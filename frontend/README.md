# Redactify Landing Page

This is a standalone static frontend for the Redactify Chrome Extension landing page.

Open locally by double-clicking:

```text
frontend/index.html
```

No development server, external images, remote fonts, CDN assets, or package install is required.

## Download button

The page's download buttons point to:

```text
frontend/downloads/redactify-dist.zip
```

Extract the zip, then open `chrome://extensions`, choose **Load unpacked**, and select the extracted `dist` folder.
